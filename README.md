# Houszy Ecommerce

Modern ecommerce platform built using Next.js, TypeScript, Tailwind CSS and .NET API integration.

## Features

- Product Listing
- Product Details
- Shopping Cart
- Guest Checkout
- Admin Panel
- Responsive Design
- Dynamic VAT Calculation
- API Integration

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- .NET API
- Context API
